# Security policy

Security fixes target the latest released version. Update before checking whether a problem still occurs.

This repository is currently private. GitHub's private vulnerability reporting and repository security advisories are available only for public repositories. Until a private reporting contact is listed here, ask the maintainer for a private channel without including vulnerability details in the issue.

If the repository becomes public and private vulnerability reporting is enabled, use [GitHub's private reporting form](https://github.com/humdedum1/vertically-challenged/security/advisories/new). In a private report, include:

- Affected extension version, browser version, and operating system.
- A description of the vulnerability and its impact.
- Minimal reproduction steps or a proof of concept using synthetic data.
- Any suggested mitigation or fix.

Do not publish exploit details in issues or pull requests, and do not include credentials or real browsing history. If no private channel is available, request one without describing the vulnerability.

The maintainer will review the report privately and coordinate disclosure after a fix is available. Response times are not guaranteed.
