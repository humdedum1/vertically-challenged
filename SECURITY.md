# Security policy

Security fixes target the latest released version. Update before checking whether a problem still occurs.

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/humdedum1/vertically-challenged/security/advisories/new). Please don't open a public issue for a security problem. In a private report, include:

- Affected extension version, browser version, and operating system.
- A description of the vulnerability and its impact.
- Minimal reproduction steps or a proof of concept using synthetic data.
- Any suggested mitigation or fix.

Do not publish exploit details in issues or pull requests, and do not include credentials or real browsing history.

The maintainer will review the report privately and coordinate disclosure after a fix is available. Response times are not guaranteed.
