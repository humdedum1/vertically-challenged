# Support

## Start here

- **Documentation:** the [README](README.md) covers installation, features, and settings. Other project docs live in [`docs/`](docs/), including [PRIVACY.md](docs/PRIVACY.md) for what data the extension stores.
- **Known problems:** search [existing issues](https://github.com/humdedum1/vertically-challenged/issues) first, including closed ones.

## Ask or report

Open an issue with the matching form from the [issue chooser](https://github.com/humdedum1/vertically-challenged/issues/new/choose):

- **Bug report:** something is broken or behaves unexpectedly. Include the extension version, browser and OS, and steps to reproduce.
- **Feature request:** an improvement or new capability. Describe the problem it solves.
- **Documentation issue:** missing, incorrect, or confusing docs.

Remove private URLs, browsing history, tokens, and personal data from logs and screenshots before attaching them.

## Security vulnerabilities

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) and report it privately through GitHub's private vulnerability reporting.

## Response times

This is a personal project maintained in spare time. Responses are not guaranteed, and a request does not imply a delivery date.
